# PDF Note Studio · final_project

[คู่มือเปิดแอปและวิธีใช้งานภาษาไทย](FINAL_PROJECT_TH.md) · [ดาวน์โหลดชุด Windows จาก GitHub Actions หลัง build สำเร็จ](https://github.com/plubngi-sys/project-/actions/workflows/final-project.yml?query=branch%3Afinal_project)

เปิดจากซอร์สบน Windows ด้วย `Start-PDFNoteStudio.cmd` หรือสร้าง ZIP แบบพร้อมใช้ด้วย `python packaging/build_windows.py`

โปรแกรมอ่าน PDF ค้นหาคำ จดโน้ตรายหน้า และสรุปภาษาไทยด้วย Ollama พร้อมจัดเก็บข้อมูลใน PostgreSQL

## เริ่มใช้งานบน Windows

1. สร้างฐานข้อมูล `pdf_note_studio` ใน pgAdmin
2. เปิด PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
$env:DATABASE_URL = 'postgresql://postgres:YOUR_PASSWORD@localhost:5432/pdf_note_studio'
.venv\Scripts\python -m database.init_db
.venv\Scripts\python project1.py
```

แทน YOUR_PASSWORD ด้วยรหัสของคุณ หากมีอักขระพิเศษให้ URL-encode และอย่าใส่รหัสจริงลง GitHub
**ผู้ที่มีตารางเดิมต้องรัน init_db อีกครั้ง** เพื่อเพิ่ม request_id และดัชนีป้องกันผล AI ซ้ำ โดยไม่ลบข้อมูลเดิม ตัวแปร DATABASE_URL ต้องตั้งใน Terminal ที่ใช้เปิดโปรแกรม
ระบบไม่โหลดไฟล์ .env อัตโนมัติ

อ่าน [รายละเอียดฐานข้อมูลและ ER Diagram](database/README.md)

## สิ่งที่ปรับปรุงเรื่องความทนทาน

- คำสั่ง PostgreSQL และการอ่านไฟล์เพื่อคำนวณ hash ทำใน worker หน้าต่างยังตอบสนองระหว่างรอ โดยพักปุ่มแก้ไข/นำทางที่เกี่ยวข้องจนรายการจบ
- กำหนด connect_timeout 5 วินาที, statement_timeout 10 วินาทีต่อ SQL และ lock_timeout 3 วินาที
- ผล AI เขียนคิว SQLite ในโฟลเดอร์ข้อมูลแอปของผู้ใช้ก่อนส่ง PostgreSQL เปิดโปรแกรมใหม่แล้วกด **บันทึกผล AI ที่ค้างอีกครั้ง** ได้
- ใช้ request_id คงเดิมในการส่งซ้ำ และตรวจ hash ของเอกสารก่อนบันทึก เพื่อไม่ผูกผลกับเอกสารที่ถูกลบแล้วสร้างใหม่ด้วยรหัสเดิม
- ฐานข้อมูลล่มยังปิดโปรแกรมได้เมื่อผล AI อยู่ในคิวบนดิสก์ พร้อมปุ่มส่งออก JSON
- ถ้าดิสก์เขียนคิวไม่ได้ ผลอยู่ในหน่วยความจำชั่วคราว ต้องลองบันทึกหรือส่งออกไปตำแหน่งที่เขียนได้ก่อนปิด
- AI จำกัดเวลารวม 120 วินาที ปุ่มยกเลิกจะยกเลิกคำขอ HTTP และรอ client ปิดการเชื่อมต่อ โดยไม่บังคับฆ่าเธรด

คิว SQLite เป็นข้อมูลพักส่งภายในเครื่อง PostgreSQL ยังคงเป็นฐานข้อมูลหลักของโปรเจกต์

## วิธีทดสอบด้วยตนเอง

1. เปิด PDF แล้วพิมพ์โน้ตหน้า 1 กด Ctrl+S
2. ไปหน้า 2 เขียนโน้ตอีกข้อความแล้วบันทึก
3. ปิดแล้วเปิดโปรแกรมใหม่ เปิดไฟล์เดิม ตรวจว่าแต่ละหน้ามีโน้ตถูกต้อง
4. ลองเปลี่ยนหน้าทั้งที่ยังไม่บันทึก ตรวจตัวเลือกบันทึก/ทิ้ง/ยกเลิก
5. เปิด Ollama และติดตั้งโมเดลด้วย `ollama pull qwen2.5:7b`
6. เริ่มวิเคราะห์หน้า 1 แล้วเปลี่ยนหน้า ตรวจว่าผล AI ถูกเก็บในหน้า 1 และไม่ทับโน้ต

7. ปิด PostgreSQL หลังเปิดเอกสารแล้ว จากนั้นเรียก AI ให้ได้ผล ตรวจว่ามีผลรอบันทึกและส่งออก JSON ได้
8. ปิดและเปิดโปรแกรมใหม่ด้วย DATABASE_URL เดิม ตรวจว่าจำนวนผลค้างยังอยู่ เปิด PostgreSQL แล้วกดบันทึกผลที่ค้าง
9. ตรวจใน ai_summaries ว่าส่งคำขอเดิมซ้ำแล้วไม่เพิ่มประวัติซ้ำ
10. กดยกเลิก AI ตรวจว่าไม่มีผลของคำขอที่ยกเลิกถูกบันทึก

## ชุดทดสอบ

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

ชุดทดสอบหน้าต่างใช้ฐานข้อมูลจำลองและไม่เรียก Ollama จริง ส่วนชุดทดสอบ PostgreSQL ต้องตั้ง TEST_DATABASE_URL ตามคู่มือ


## ขอบเขตที่ยังต้องทำต่อ

รูปย่อและการค้นหาทั้งเล่มยังทำในเธรดหน้าต่าง จึงอาจรอเมื่อ PDF ใหญ่มาก
ยังต้องตรวจ PostgreSQL/Ollama จริงบนเครื่องผู้ใช้และตรวจ schema constraints เพิ่มเติม
การคัดลอกไฟล์คิวด้วยตนเองควรปิดโปรแกรมก่อน คิวแยกตาม host/port/database/user/service
การเปลี่ยนชื่อฐานข้อมูลหรือผู้ใช้จะเห็นคิวอีกชุด ต้องกลับมาใช้ค่าการเชื่อมต่อเดิมเพื่อกู้คิวเก่า
โน้ตที่ยังไม่ได้กดบันทึกไม่ได้อยู่ในคิว AI และยังอาจหายหากเครื่องดับ

## เมนูทบทวน

อัปเกรดฐานข้อมูลด้วย `python -m database.init_db` ใน PowerShell ที่ตั้ง DATABASE_URL ไว้
สคริปต์เพิ่มตาราง page_flags และ flashcards โดยใช้ฐานข้อมูลเดิม

- ปักธงหน้านี้เพื่อจดสิ่งที่ยังสงสัย เปิดรายการหน้าที่ปักธงเพื่อกลับไปอ่านหรือเปลี่ยนสถานะ
- ตั้งคำถามให้โน้ตหน้าปัจจุบัน ข้อความโน้ตขณะสร้างจะเป็นคำตอบของแฟลชการ์ด พลิกดูแล้วเลือกจำได้หรือทวนอีกครั้ง
- รวมชีทก่อนสอบโดยเลือกรายการโน้ตและผล AI ที่บันทึกแล้วจากหลาย PDF ส่งออกเป็นข้อความภาษาไทยพร้อมชื่อไฟล์และเลขหน้า
- ถามชีทที่เปิดอยู่ โปรแกรมคัดข้อความจากสูงสุดสามหน้าด้วยคำค้น แล้วให้ Ollama ตอบพร้อมเลขหน้าและข้อความอ้างอิงที่ตรวจสอบกับต้นฉบับได้ การค้นหานี้ใช้ข้อความที่สกัดจาก PDF และไม่มี OCR สำหรับภาพสแกน
